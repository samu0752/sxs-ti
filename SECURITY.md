# Segurança

## Versão acompanhada

Correções são direcionadas à linha `1.0.x`.

## Relato privado

Use **Security → Report a vulnerability** no repositório GitHub quando habilitado. Se esse canal não estiver disponível, solicite um contato privado ao mantenedor antes de compartilhar detalhes. Informe ambiente, versão, impacto e passos mínimos para verificação usando dados fictícios.

O [modelo de ameaças](docs/SEGURANCA.md) descreve os controles e os limites de implantação.
