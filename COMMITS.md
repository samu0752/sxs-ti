# Sequência proposta de commits

A árvore do ZIP está no estado final. Cada comando corresponde à etapa indicada e pressupõe que seus arquivos foram preparados no índice com `git add`.

1. `git commit -m "chore: preserve a estrutura da central existente"`
2. `git commit -m "chore: fixe as dependências de execução"`
3. `git commit -m "chore: configure as ferramentas de desenvolvimento"`
4. `git commit -m "chore: adicione a automação local e os hooks"`
5. `git commit -m "ci: valide código, segurança e cobertura"`
6. `git commit -m "ci: configure as atualizações automáticas"`
7. `git commit -m "fix: ajuste o comando de build e a verificação do Render"`
8. `git commit -m "feat: versione o esquema SQLite"`
9. `git commit -m "feat: migre o banco já existente"`
10. `git commit -m "feat: registre autenticação e ações administrativas"`
11. `git commit -m "feat: limite tentativas e bloqueie contas temporariamente"`
12. `git commit -m "fix: aplique os cabeçalhos de segurança"`
13. `git commit -m "test: verifique isolamento entre solicitantes"`
14. `git commit -m "feat: classifique incidentes, requisições e problemas"`
15. `git commit -m "feat: calcule SLA em horário comercial"`
16. `git commit -m "feat: pause SLA enquanto aguarda o solicitante"`
17. `git commit -m "feat: alerte e escalone chamados próximos do vencimento"`
18. `git commit -m "feat: valide e armazene anexos"`
19. `git commit -m "test: cubra anexos inválidos e a autorização de download"`
20. `git commit -m "feat: registre notificações simuladas em JSON"`
21. `git commit -m "feat: publique e sugira artigos por categoria"`
22. `git commit -m "feat: colete e exiba avaliações CSAT"`
23. `git commit -m "feat: cadastre e vincule ativos de TI"`
24. `git commit -m "feat: inclua macros para respostas técnicas"`
25. `git commit -m "feat: relacione chamados e registre duplicidades"`
26. `git commit -m "feat: adicione indicadores operacionais ao painel"`
27. `git commit -m "feat: exporte relatórios e analise dados fictícios"`
28. `git commit -m "feat: permita restaurar os chamados de demonstração"`
29. `git commit -m "docs: descreva o uso, as decisões e os controles"`
30. `git commit -m "docs: documente a versão 1.0.0 e o histórico proposto"`
